# Validation Checklist

- [ ] Required directories exist.
- [ ] Standard Python workflow runs without external packages.
- [ ] Outputs are generated.
- [ ] SQL schema loads in SQLite if available.
- [ ] Advanced Python workflow fails gracefully if dependencies are missing.
- [ ] Shocks reference valid scenarios.
- [ ] Institutions reference valid development futures.
- [ ] Development pathways reference valid futures and scenarios.
- [ ] Outputs include development profile scores, scenario scores, policy scores, shock scores, institutional scores, pathway simulations, and a reproducibility report.
