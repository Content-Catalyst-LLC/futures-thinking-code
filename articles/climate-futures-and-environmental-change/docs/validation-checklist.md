# Validation Checklist

- [ ] Required directories exist.
- [ ] Standard Python workflow runs without external packages.
- [ ] Outputs are generated.
- [ ] SQL schema loads in SQLite if available.
- [ ] Advanced Python workflow fails gracefully if dependencies are missing.
- [ ] Mitigation/adaptation strategies reference valid climate profiles.
- [ ] Risk indicators reference valid climate scenarios.
- [ ] Governance records reference valid climate profiles.
- [ ] Climate pathways reference valid profiles and scenarios.
- [ ] Outputs include climate profile scores, scenario scores, strategy scores, risk-priority scores, governance-capacity scores, pathway simulations, and a reproducibility report.
