# Methodology

This companion repository treats security futures and hybrid risk as dynamic systems shaped by threat diversity, cyber exposure, infrastructure dependence, information vulnerability, climate-security stress, resource dependence, institutional coordination, civilian protection, adaptive resilience, public trust, and attribution clarity.

## Core Analytical Tasks

1. Validate security profiles, scenarios, strategies, risk indicators, infrastructure dependencies, and adaptive pathways.
2. Score security profiles for hybrid risk and security resilience.
3. Score scenarios for hybrid security stress and response opportunity.
4. Score strategy options for security value and implementation readiness.
5. Score risk indicators for hybrid-risk priority.
6. Score infrastructure dependencies for cascade exposure.
7. Simulate hybrid risk, cascade pressure, security resilience, and public trust over time.
8. Export reproducible tables and a report.

## Core Equations

### Hybrid Risk

`risk = 0.13 × cyber_exposure + 0.13 × infrastructure_dependence + 0.13 × information_vulnerability + 0.12 × climate_security_stress + 0.10 × resource_dependence + 0.11 × (1 - institutional_coordination) + 0.10 × (1 - civilian_protection) + 0.10 × (1 - adaptive_resilience) + 0.05 × (1 - public_trust) + 0.03 × (1 - attribution_clarity)`

### Security Resilience

`resilience = 0.20 × institutional_coordination + 0.22 × civilian_protection + 0.22 × adaptive_resilience + 0.16 × public_trust + 0.08 × attribution_clarity + 0.04 × (1 - cyber_exposure) + 0.04 × (1 - information_vulnerability) + 0.04 × (1 - infrastructure_dependence)`

### Cascade Exposure

`cascade = dependency_weight × disruption_sensitivity × public_harm_potential × (1 - recovery_capacity)`

## Interpretation

Scores are not predictions. They are structured prompts for comparing security futures, surfacing cascade vulnerabilities, testing resilience strategies, and assessing whether institutions can protect essential functions, public trust, rights, and civilian life under hybrid stress.
