# Colonial Futures and Contested Imagination

This is the professional companion repository directory for the Futures Thinking article:

**Colonial Futures and Contested Imagination**

## Purpose

This directory operationalizes colonial futures and contested imagination as a reproducible coloniality-risk, reparative-capacity, extraction-burden, consent-quality, epistemic-justice, community-voice, and future-making legitimacy workflow. It includes synthetic future-making profiles, contested-future scenarios, strategy options, risk indicators, extraction/voice records, adaptive pathway parameters, SQL schemas, documentation, generated outputs, and multi-language computational examples.

## Directory

`articles/colonial-futures-and-contested-imagination/`

## Structure

- `python/` — standard-library and optional advanced workflows for coloniality risk, reparative capacity, extraction burden, community voice, legitimacy, and contested future-making simulations.
- `r/` — base R workflows for comparing colonial future-making profiles and reparative gaps.
- `julia/` — coloniality-risk scoring examples.
- `sql/` — schemas for future profiles, scenarios, strategies, risks, extraction records, and adaptive pathways.
- `rust/` — command-line coloniality-risk scoring scaffold.
- `go/` — coloniality scoring utility scaffold.
- `cpp/` — efficient scoring examples.
- `fortran/` — numerical coloniality-risk examples.
- `c/` — low-level scoring utility.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/colonial_futures_contested_imagination_advanced.py
```
