# Future Directions in Strategic Foresight

This is the professional companion repository directory for the Futures Thinking article:

**Future Directions in Strategic Foresight**

## Purpose

This directory operationalizes next-generation strategic foresight as a reproducible capability-scoring, signal-detection, scenario-updating, governance-integration, participatory-legitimacy, ethical-accountability, adaptive-strategy, and institutional-learning workflow. It includes synthetic institutional profiles, foresight-system scenarios, strategy options, risk indicators, signal records, adaptive strategy pathways, SQL schemas, documentation, generated outputs, and multi-language computational examples.

## Directory

`articles/future-directions-in-strategic-foresight/`

## Structure

- `python/` — standard-library and optional advanced workflows for foresight capability, dynamic scenario updating, strategy viability, governance integration, and institutional learning.
- `r/` — base R workflows for comparing foresight capability across institutions.
- `julia/` — foresight capability scoring example.
- `sql/` — schemas for institutional profiles, foresight scenarios, strategy options, risk indicators, signal records, and adaptive pathways.
- `rust/` — command-line foresight capability scoring scaffold.
- `go/` — foresight scoring utility scaffold.
- `cpp/` — efficient scoring examples.
- `fortran/` — numerical capability scoring example.
- `c/` — low-level scoring utility.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/future_directions_strategic_foresight_advanced.py
```
