# Methodology

This companion repository treats horizon scanning as a structured foresight workflow.

## Core Analytical Tasks

1. Score scanned signals for strategic relevance.
2. Audit source diversity and blind-spot risk.
3. Cluster related signals into emerging issue areas.
4. Score assumption vulnerability.
5. Prioritize watchlist signals.
6. Compare institutional scanning-system effectiveness.

## Core Equations

### Horizon Scanning Profile

`profile = 0.10 × visibility - 0.08 × ambiguity + 0.22 × structural_connection + 0.18 × domain_diversity + 0.14 × source_diversity + 0.14 × assumption_challenge + 0.30 × strategic_relevance`

### Source Value

`source_value = reliability × (1 - blind_spot_risk) + 0.20 × community_source + 0.10 × scientific_source + 0.10 × policy_source`

### Cluster Priority

`cluster_priority = coherence × strategic_concern`

### Assumption Vulnerability

`vulnerability = exposure × (1 - confidence) × (1 + (1 - reversibility))`

### Watchlist Priority

`watch_priority = 0.70 × decision_linkage + 0.30 × review_frequency_weight`

### Scanning Effectiveness

`effectiveness = signal_strength + filtering_quality + source_diversity + institutional_uptake - ambiguity - resistance`

## Interpretation

The workflow does not predict the future. It makes signal detection, filtering, source diversity, clustering, and institutional uptake more explicit and auditable.
