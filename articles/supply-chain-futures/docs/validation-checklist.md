# Validation Checklist

- [ ] Required directories exist.
- [ ] Standard Python workflow runs without external packages.
- [ ] Outputs are generated.
- [ ] SQL schema loads in SQLite if available.
- [ ] Advanced Python workflow fails gracefully if dependencies are missing.
- [ ] Resilience strategies reference valid supply chain profiles.
- [ ] Chokepoints reference valid scenarios.
- [ ] Procurement/circularity records reference valid profiles.
- [ ] Disruption pathways reference valid profiles and scenarios.
- [ ] Outputs include supply profile scores, scenario scores, strategy scores, chokepoint risk, procurement/circularity scores, disruption simulations, and a reproducibility report.
