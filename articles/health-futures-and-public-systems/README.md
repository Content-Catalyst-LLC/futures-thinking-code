# Health Futures and Public Systems

This is the professional companion repository directory for the Futures Thinking article:

**Health Futures and Public Systems**

## Purpose

This directory operationalizes health futures and public systems as a reproducible population-health and public-systems foresight workflow. It includes synthetic health system profiles, scenario records, strategy options, risk indicators, governance records, public-system stress pathways, SQL schemas, documentation, generated outputs, and multi-language computational examples.

## Directory

`articles/health-futures-and-public-systems/`

## Structure

- `python/` — standard-library and optional advanced workflows for public health resilience, fragility, scenario stress, strategy value, risk priority, governance capacity, and system-stress simulation.
- `r/` — base R workflows for comparing health futures profiles.
- `julia/` — health system resilience scoring examples.
- `sql/` — schemas for profiles, scenarios, strategies, risk indicators, governance records, and pathways.
- `rust/` — command-line health resilience scoring scaffold.
- `go/` — health futures utility scaffold.
- `cpp/` — efficient scoring examples.
- `fortran/` — numerical public health resilience examples.
- `c/` — low-level scoring utility.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/health_futures_advanced.py
```
