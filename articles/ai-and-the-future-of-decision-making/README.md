# AI and the Future of Decision-Making

This is the professional companion repository directory for the Futures Thinking article:

**AI and the Future of Decision-Making**

## Purpose

This directory operationalizes AI and the future of decision-making as a reproducible futures workflow. It includes synthetic decision-system profiles, governance controls, risk indicators, equity and harm indicators, uncertainty scenarios, pathway simulations, SQL schemas, documentation, generated outputs, and multi-language computational examples.

## Directory

`articles/ai-and-the-future-of-decision-making/`

## Structure

- `python/` — standard-library and optional advanced workflows for hybrid decision quality, governance readiness, uncertainty pressure, harm risk, equity protection, and reproducible reports.
- `r/` — base R workflows for decision-system profiles and governance risk comparison.
- `julia/` — hybrid decision score examples.
- `sql/` — schemas for decision systems, governance controls, risks, equity indicators, uncertainty scenarios, pathway parameters, and strategy options.
- `rust/` — command-line hybrid decision score scaffold.
- `go/` — decision quality utility scaffold.
- `cpp/` — efficient decision-system scoring examples.
- `fortran/` — numerical hybrid decision examples.
- `c/` — low-level decision score utility.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/ai_decision_making_advanced.py
```
