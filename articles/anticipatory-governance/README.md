# Anticipatory Governance

This is the professional companion repository directory for the Futures Thinking article:

**Anticipatory Governance**

## Purpose

This directory operationalizes anticipatory governance as a reproducible public-sector foresight workflow. It includes synthetic governance strategy profiles, weak-signal records, emerging-risk records, scenario profiles, adaptive pathway simulations, strategy options, SQL schemas, documentation, generated outputs, and multi-language computational examples.

## Directory

`articles/anticipatory-governance/`

## Structure

- `python/` — standard-library and optional advanced workflows for anticipatory capacity, early warning, risk priority, strategy scoring, pathway simulation, legitimacy, learning, and reproducible reports.
- `r/` — base R workflows for anticipatory governance profile comparison.
- `julia/` — anticipatory capacity scoring examples.
- `sql/` — schemas for governance profiles, weak signals, emerging risks, scenario profiles, adaptive pathways, and strategy options.
- `rust/` — command-line anticipatory capacity scaffold.
- `go/` — anticipatory governance utility scaffold.
- `cpp/` — efficient scoring examples.
- `fortran/` — numerical anticipatory capacity examples.
- `c/` — low-level scoring utility.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/anticipatory_governance_advanced.py
```
