# Futures Thinking in Public Policy

This is the professional companion repository directory for the Futures Thinking article:

**Futures Thinking in Public Policy**

## Purpose

This directory operationalizes futures thinking in public policy as a reproducible governance workflow. It includes synthetic policy option records, future scenario profiles, institutional capacity indicators, risk registers, equity indicators, adaptive pathway simulations, strategy options, SQL schemas, documentation, generated outputs, and multi-language computational examples.

## Directory

`articles/futures-thinking-in-public-policy/`

## Structure

- `python/` — standard-library and optional advanced workflows for policy robustness, anticipatory capacity, scenario stress testing, legitimacy, equity, implementation difficulty, adaptive learning, early warning, and reproducible reports.
- `r/` — base R workflows for comparing policy futures profiles.
- `julia/` — policy robustness scoring examples.
- `sql/` — schemas for policy options, scenario profiles, institutional capacity, policy risk registers, adaptive pathways, and strategy options.
- `rust/` — command-line policy robustness scaffold.
- `go/` — public policy futures utility scaffold.
- `cpp/` — efficient scoring examples.
- `fortran/` — numerical policy viability examples.
- `c/` — low-level scoring utility.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/public_policy_futures_advanced.py
```
