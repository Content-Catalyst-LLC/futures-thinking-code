# The History of Futures Thinking

This is the professional companion repository directory for the Futures Thinking article:

**The History of Futures Thinking**

## Purpose

This directory operationalizes the history of futures thinking as a structured research workflow. It includes synthetic but realistic datasets for historical traditions, institutional origins, method genealogies, timeline periods, power-risk analysis, reflective foresight scoring, SQL schemas, documentation, generated outputs, and multi-language computational examples.

## Directory

`articles/the-history-of-futures-thinking/`

## Structure

- `python/` — standard-library and optional advanced workflows for historical futures analysis.
- `r/` — base R workflows for tradition scoring and historical comparison.
- `julia/` — dynamic historical-tradition scoring examples.
- `sql/` — schemas for traditions, institutions, methods, timeline periods, and risk scores.
- `rust/` — command-line historical diagnostics scaffold.
- `go/` — historical-tradition scoring utility scaffold.
- `cpp/` — efficient scoring example.
- `fortran/` — numerical scoring example.
- `c/` — low-level scoring utility.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/history_futures_advanced.py
```
