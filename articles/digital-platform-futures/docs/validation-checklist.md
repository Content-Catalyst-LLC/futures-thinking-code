# Validation Checklist

- [ ] Required directories exist.
- [ ] Standard Python workflow runs without external packages.
- [ ] Outputs are generated.
- [ ] SQL schema loads in SQLite if available.
- [ ] Advanced Python workflow fails gracefully if dependencies are missing.
- [ ] Risk records reference valid platforms.
- [ ] Accountability indicators reference valid platforms.
- [ ] Pathway parameters reference valid scenarios.
- [ ] Outputs include platform scores, risk scores, accountability scores, scenario scores, pathway simulation, and strategy scores.
- [ ] Reproducibility report is generated.
