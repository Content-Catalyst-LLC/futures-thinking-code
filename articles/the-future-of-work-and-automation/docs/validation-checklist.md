# Validation Checklist

- [ ] Required directories exist.
- [ ] Standard Python workflow runs without external packages.
- [ ] Outputs are generated.
- [ ] SQL schema loads in SQLite if available.
- [ ] Advanced Python workflow fails gracefully if dependencies are missing.
- [ ] Task exposure records reference valid occupations.
- [ ] Algorithmic management risks reference valid occupations.
- [ ] Social protection records reference valid occupations.
- [ ] Pathway parameters reference valid occupations.
- [ ] Outputs include occupation exposure, task exposure, scenario scores, social protection scores, pathway simulation, and strategy scores.
- [ ] Reproducibility report is generated.
