# Futures Literacy and Anticipatory Capacity

This is the professional companion repository directory for the Futures Thinking article:

**Futures Literacy and Anticipatory Capacity**

## Purpose

This directory operationalizes futures literacy and anticipatory capacity through reproducible examples. It includes synthetic but realistic data, assumption vulnerability scoring, signal watch scoring, institutional anticipatory-capacity profiles, participatory futures indicators, strategy-translation tables, SQL schemas, documentation, and multi-language computational examples.

## Directory

`articles/futures-literacy-and-anticipatory-capacity/`

## Structure

- `python/` — standard-library and optional advanced workflows for futures literacy diagnostics.
- `r/` — base R workflows for anticipatory capacity profiles and signal summaries.
- `julia/` — dynamic anticipatory-capacity example.
- `sql/` — schemas for assumptions, signals, future images, learning cycles, and strategy translation.
- `rust/` — command-line scoring scaffold.
- `go/` — signal and capacity utility scaffold.
- `cpp/` — efficient scoring example.
- `fortran/` — numerical capacity example.
- `c/` — low-level scoring utility.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/futures_literacy_advanced.py
```
