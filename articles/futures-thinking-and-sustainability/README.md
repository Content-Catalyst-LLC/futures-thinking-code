# Futures Thinking and Sustainability

This is the professional companion repository directory for the Futures Thinking article:

**Futures Thinking and Sustainability**

## Purpose

This directory operationalizes futures thinking and sustainability as a reproducible sustainability-foresight workflow. It includes synthetic sustainability future profiles, scenarios, transition strategies, risk indicators, governance records, transition pathway simulations, SQL schemas, documentation, generated outputs, and multi-language computational examples.

## Directory

`articles/futures-thinking-and-sustainability/`

## Structure

- `python/` — standard-library and optional advanced workflows for sustainability profile scoring, fragility scoring, scenario comparison, risk priority, governance capacity, and transition-pathway simulation.
- `r/` — base R workflows for comparing sustainability future profiles.
- `julia/` — sustainability viability scoring examples.
- `sql/` — schemas for sustainability profiles, scenarios, transition strategies, risk indicators, governance records, and transition pathways.
- `rust/` — command-line sustainability scoring scaffold.
- `go/` — sustainability futures utility scaffold.
- `cpp/` — efficient scoring examples.
- `fortran/` — numerical sustainability examples.
- `c/` — low-level scoring utility.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/sustainability_futures_advanced.py
```
