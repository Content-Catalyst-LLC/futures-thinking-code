# Geopolitical Futures

Professional companion repository for the article **Geopolitical Futures**.

## Purpose

This directory turns the article into a reproducible geopolitical foresight workflow. It includes synthetic geopolitical future profiles, scenarios, strategic options, risk indicators, governance records, interaction simulations, SQL schema, R/Python workflows, and multi-language scoring examples.

## Quick Start

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/geopolitical_futures_advanced.py
```
