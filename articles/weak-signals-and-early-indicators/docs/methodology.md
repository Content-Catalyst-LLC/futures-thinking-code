# Methodology

This companion repository treats weak signal analysis as structured interpretation under ambiguity.

## Core Analytical Tasks

1. Score weak signal profiles.
2. Track transition from weak signals to early indicators.
3. Cluster related signals into possible emerging issue areas.
4. Score propagation pathways and system receptivity.
5. Identify vulnerable assumptions.
6. Build a monitoring watchlist with owners and trigger conditions.

## Core Equations

### Weak Signal Profile

`profile = 0.10 × visibility - 0.08 × ambiguity + 0.24 × systemic_connection + 0.22 × propagation_potential + 0.12 × institutional_recognition + 0.12 × distributional_relevance + 0.20 × monitoring_urgency`

### Early Indicator Score

`indicator_score = 0.25 × repetition + 0.25 × clarity + 0.20 × measurement_quality + 0.20 × policy_attention + 0.10 × evidence_index`

### Cluster Priority

`cluster_priority = coherence × strategic_concern`

### Propagation Strength

`propagation_strength = 0.25 × adoption + 0.25 × feedback + 0.20 × recognition + 0.15 × legitimacy - 0.20 × friction`

### Assumption Vulnerability

`vulnerability = exposure × (1 - confidence) × (1 + (1 - reversibility))`

### Watchlist Priority

`watch_priority = 0.70 × decision_linkage + 0.30 × review_frequency_weight`

## Interpretation

The workflow does not predict which weak signal will become a trend. It makes signal interpretation, propagation conditions, evidence accumulation, and monitoring logic more transparent and easier to revise.
