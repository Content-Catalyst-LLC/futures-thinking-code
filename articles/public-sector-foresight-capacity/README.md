# Public-Sector Foresight Capacity

This is the professional companion repository directory for the Futures Thinking article:

**Public-Sector Foresight Capacity**

## Purpose

This directory operationalizes public-sector foresight capacity as a reproducible governance workflow. It includes synthetic foresight-capacity profiles, scanning signals, decision-uptake records, scenario-cycle records, adaptive pathway simulations, strategy options, SQL schemas, documentation, generated outputs, and multi-language computational examples.

## Directory

`articles/public-sector-foresight-capacity/`

## Structure

- `python/` — standard-library and optional advanced workflows for foresight capacity, signal priority, decision uptake, scenario cycles, institutional learning, legitimacy, implementation authority, and reproducible reports.
- `r/` — base R workflows for comparing public-sector foresight capacity profiles.
- `julia/` — foresight capacity scoring examples.
- `sql/` — schemas for capacity profiles, scanning signals, decision uptake, scenario cycles, pathways, and strategy options.
- `rust/` — command-line foresight capacity scaffold.
- `go/` — public-sector foresight utility scaffold.
- `cpp/` — efficient scoring examples.
- `fortran/` — numerical foresight capacity examples.
- `c/` — low-level scoring utility.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/public_sector_foresight_capacity_advanced.py
```
