# Validation Checklist

- [ ] Required directories exist.
- [ ] Standard Python workflow runs without external packages.
- [ ] Outputs are generated.
- [ ] SQL schema loads in SQLite if available.
- [ ] Advanced Python workflow fails gracefully if dependencies are missing.
- [ ] Data dictionary matches CSV columns.
- [ ] Driver register includes impact, uncertainty, urgency, interaction, burden, monitoring, evidence, and controllability.
- [ ] Interaction map includes directed cross-impact weights.
- [ ] Monitoring indicators include thresholds and decision responses.
- [ ] Assumption register includes confidence, fragility, and revision rules.
