# Institutional Adaptation to Long-Term Change

This is the professional companion repository directory for the Futures Thinking article:

**Institutional Adaptation to Long-Term Change**

## Purpose

This directory operationalizes institutional adaptation to long-term change as a reproducible futures workflow. It includes synthetic institutional profiles, adaptation pressure records, feedback indicators, legitimacy indicators, scenario profiles, pathway simulations, strategy options, SQL schemas, documentation, generated outputs, and multi-language computational examples.

## Directory

`articles/institutional-adaptation-to-long-term-change/`

## Structure

- `python/` — standard-library and optional advanced workflows for adaptive profile scoring, institutional fragility, learning capacity, legitimacy, feedback sensitivity, resource mobility, pathway simulation, and reproducible reports.
- `r/` — base R workflows for institutional adaptation profile comparison.
- `julia/` — adaptation scoring examples.
- `sql/` — schemas for institutional profiles, adaptation risks, feedback indicators, scenario profiles, adaptive pathways, and strategy options.
- `rust/` — command-line adaptive profile scaffold.
- `go/` — institutional adaptation utility scaffold.
- `cpp/` — efficient scoring examples.
- `fortran/` — numerical institutional adaptation examples.
- `c/` — low-level scoring utility.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/institutional_adaptation_advanced.py
```
