# Validation Checklist

- [ ] Required directories exist.
- [ ] Standard Python workflow runs without external packages.
- [ ] Outputs are generated.
- [ ] SQL schema loads in SQLite if available.
- [ ] Advanced Python workflow fails gracefully if dependencies are missing.
- [ ] Strategic options reference valid strategy profiles.
- [ ] Capabilities reference valid strategy profiles.
- [ ] Early-warning indicators reference valid scenarios.
- [ ] Dynamic capability pathways reference valid strategies and scenarios.
- [ ] Outputs include strategy scores, option scores, capability priorities, indicator urgency, scenario stress tests, pathway simulations, and a reproducibility report.
