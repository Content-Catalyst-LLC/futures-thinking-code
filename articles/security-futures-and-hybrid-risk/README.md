# Security Futures and Hybrid Risk

This is the professional companion repository directory for the Futures Thinking article:

**Security Futures and Hybrid Risk**

## Purpose

This directory operationalizes security futures and hybrid risk as a reproducible hybrid-threat, cascade-risk, resilience, public-trust, and adaptive-security workflow. It includes synthetic security profiles, scenario records, strategy options, risk indicators, infrastructure dependency records, adaptive pathway parameters, SQL schemas, documentation, generated outputs, and multi-language computational examples.

## Directory

`articles/security-futures-and-hybrid-risk/`

## Structure

- `python/` — standard-library and optional advanced workflows for hybrid risk, cascade pressure, security resilience, public trust, strategy scoring, and adaptive security simulations.
- `r/` — base R workflows for comparing hybrid security futures and resilience gaps.
- `julia/` — hybrid-risk scoring examples.
- `sql/` — schemas for security profiles, scenarios, strategies, indicators, infrastructure dependencies, and adaptive pathways.
- `rust/` — command-line hybrid-risk scoring scaffold.
- `go/` — security risk utility scaffold.
- `cpp/` — efficient scoring examples.
- `fortran/` — numerical hybrid-risk examples.
- `c/` — low-level scoring utility.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/security_futures_hybrid_risk_advanced.py
```
