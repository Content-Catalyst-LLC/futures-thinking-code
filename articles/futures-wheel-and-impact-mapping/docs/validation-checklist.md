# Validation Checklist

- [ ] Required directories exist.
- [ ] Standard Python workflow runs without external packages.
- [ ] Outputs are generated.
- [ ] SQL schema loads in SQLite if available.
- [ ] Advanced Python workflow fails gracefully if dependencies are missing.
- [ ] Data dictionary matches CSV columns.
- [ ] Consequence nodes include first-, second-, and third-order effects.
- [ ] Impact pathways include goals, actors, impacts, deliverables, and indicators.
- [ ] Distributional audit identifies exposure, capacity, voice, and burden-shifting risk.
- [ ] Monitoring indicators include review frequency and decision triggers.
