# Validation Checklist

- [ ] Required directories exist.
- [ ] Standard Python workflow runs without external packages.
- [ ] Outputs are generated.
- [ ] SQL schema loads in SQLite if available.
- [ ] Advanced Python workflow fails gracefully if dependencies are missing.
- [ ] Policy options reference valid financial profiles.
- [ ] Risk indicators reference valid financial scenarios.
- [ ] Public finance and climate records reference valid profiles.
- [ ] Stress pathways reference valid profiles and scenarios.
- [ ] Outputs include financial profile scores, scenario scores, policy scores, risk-priority scores, public-finance/climate scores, stress simulations, and a reproducibility report.
