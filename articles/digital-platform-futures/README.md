# Digital Platform Futures

This is the professional companion repository directory for the Futures Thinking article:

**Digital Platform Futures**

## Purpose

This directory operationalizes digital platform futures as a reproducible futures workflow. It includes synthetic platform profiles, governance indicators, risk registers, accountability indicators, scenario profiles, pathway simulations, strategy options, SQL schemas, documentation, generated outputs, and multi-language computational examples.

## Directory

`articles/digital-platform-futures/`

## Structure

- `python/` — standard-library and optional advanced workflows for platform power, dependency pressure, interoperability, public accountability, labor protection, user rights, ecological responsibility, digital public value, and reproducible reports.
- `r/` — base R workflows for platform scenario comparison and public-interest platform scoring.
- `julia/` — public-interest platform capacity scoring examples.
- `sql/` — schemas for platform profiles, risk registers, accountability indicators, scenario profiles, pathway parameters, and strategy options.
- `rust/` — command-line platform capacity scaffold.
- `go/` — public-interest platform utility scaffold.
- `cpp/` — efficient scoring examples.
- `fortran/` — numerical platform capacity examples.
- `c/` — low-level scoring utility.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/digital_platform_futures_advanced.py
```
