# Energy Transition Futures

This is the professional companion repository directory for the Futures Thinking article:

**Energy Transition Futures**

## Purpose

This directory operationalizes energy transition futures as a reproducible futures workflow. It includes synthetic technology records, infrastructure indicators, justice indicators, transition risks, scenario profiles, pathway simulations, strategy options, SQL schemas, documentation, generated outputs, and multi-language computational examples.

## Directory

`articles/energy-transition-futures/`

## Structure

- `python/` — standard-library and optional advanced workflows for transition readiness, grid constraints, emissions pressure, justice-resilience capacity, material risk, pathway simulation, and reproducible reports.
- `r/` — base R workflows for energy transition scenario comparison and transition-readiness scoring.
- `julia/` — transition-readiness scoring examples.
- `sql/` — schemas for technology records, risk registers, justice indicators, scenario profiles, pathway parameters, and strategy options.
- `rust/` — command-line transition-readiness scaffold.
- `go/` — energy transition utility scaffold.
- `cpp/` — efficient scoring examples.
- `fortran/` — numerical transition-readiness examples.
- `c/` — low-level scoring utility.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/energy_transition_futures_advanced.py
```
