# Data Dictionary

## scenarios.csv

Synthetic scenario set with archetype, plausibility, system stress, and time horizon.

## strategies.csv

Strategy options scored for adaptability, equity sensitivity, and implementation difficulty.

## strategy_performance.csv

Strategy-by-scenario performance matrix used for robustness and regret analysis.

## drivers_uncertainties.csv

Drivers and critical uncertainties scored by uncertainty, impact, and velocity.

## signals.csv

Emerging signals scored by uncertainty, impact, novelty, source type, and monitoring priority.

## assumptions.csv

Assumptions scored for confidence, exposure, reversibility, and monitoring signals.

## scenario_framework.csv

Scenario-axis structure for building scenario matrices and contrasting future environments.
