# Hope, Dread, and the Politics of the Future

This is the professional companion repository directory for the Futures Thinking article:

**Hope, Dread, and the Politics of the Future**

## Purpose

This directory operationalizes hope, dread, and the politics of the future as a reproducible disciplined-hope, paralysis-risk, mobilization, fear-politics, future-fatigue, agency, trust, repair-capacity, and narrative-accountability workflow. It includes synthetic future-emotion profiles, political future scenarios, strategy options, risk indicators, affective records, adaptive pathway parameters, SQL schemas, documentation, generated outputs, and multi-language computational examples.

## Directory

`articles/hope-dread-and-the-politics-of-the-future/`

## Structure

- `python/` — standard-library and optional advanced workflows for disciplined hope, dread, agency, trust, mobilization, paralysis risk, fear politics, and future fatigue.
- `r/` — base R workflows for comparing future-emotion profiles and political affect gaps.
- `julia/` — disciplined-hope scoring examples.
- `sql/` — schemas for profiles, scenarios, strategies, risk indicators, future-emotion records, and adaptive pathways.
- `rust/` — command-line disciplined-hope scoring scaffold.
- `go/` — disciplined-hope scoring utility scaffold.
- `cpp/` — efficient scoring examples.
- `fortran/` — numerical future-emotion examples.
- `c/` — low-level scoring utility.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/hope_dread_politics_future_advanced.py
```
