# Validation Checklist

- [ ] Required directories exist.
- [ ] Standard Python workflow runs without external packages.
- [ ] Outputs are generated.
- [ ] SQL schema loads in SQLite if available.
- [ ] Advanced Python workflow fails gracefully if dependencies are missing.
- [ ] Representation records reference valid participation models.
- [ ] Decision uptake records reference valid participation models.
- [ ] Democratic pathways reference valid participation models and scenarios.
- [ ] Outputs include capacity scores, representation scores, uptake scores, scenario scores, pathway simulation, and strategy scores.
- [ ] Reproducibility report is generated.
