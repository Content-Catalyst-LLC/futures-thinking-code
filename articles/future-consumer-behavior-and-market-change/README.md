# Future Consumer Behavior and Market Change

This is the professional companion repository directory for the Futures Thinking article:

**Future Consumer Behavior and Market Change**

## Purpose

This directory operationalizes future consumer behavior and market change as a reproducible consumer-futures workflow. It includes synthetic consumer future profiles, market scenarios, strategy options, vulnerability indicators, regulatory records, adoption pathway simulations, SQL schemas, documentation, generated outputs, and multi-language computational examples.

## Directory

`articles/future-consumer-behavior-and-market-change/`

## Structure

- `python/` — standard-library and optional advanced workflows for consumer future profiles, trust dynamics, market fragility, vulnerability, scenario stress testing, strategy options, and adoption-pathway simulation.
- `r/` — base R workflows for comparing consumer future profiles.
- `julia/` — consumer future scoring examples.
- `sql/` — schemas for consumer profiles, scenarios, strategy options, vulnerability records, regulatory records, and adoption pathways.
- `rust/` — command-line consumer futures scoring scaffold.
- `go/` — consumer market futures utility scaffold.
- `cpp/` — efficient scoring examples.
- `fortran/` — numerical consumer future examples.
- `c/` — low-level scoring utility.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/consumer_market_futures_advanced.py
```
