# Democratic Futures and Public Participation

This is the professional companion repository directory for the Futures Thinking article:

**Democratic Futures and Public Participation**

## Purpose

This directory operationalizes democratic futures and public participation as a reproducible foresight workflow. It includes synthetic participation models, representation records, deliberative process indicators, decision-uptake records, future-scenario profiles, pathway simulations, strategy options, SQL schemas, documentation, generated outputs, and multi-language computational examples.

## Directory

`articles/democratic-futures-and-public-participation/`

## Structure

- `python/` — standard-library and optional advanced workflows for democratic futures capacity, tokenism risk, representation quality, deliberative quality, decision uptake, public trust, and reproducible reports.
- `r/` — base R workflows for comparing participatory foresight models.
- `julia/` — democratic futures capacity scoring examples.
- `sql/` — schemas for participation models, representation profiles, decision uptake, scenarios, pathways, and strategies.
- `rust/` — command-line democratic futures capacity scaffold.
- `go/` — democratic foresight utility scaffold.
- `cpp/` — efficient scoring examples.
- `fortran/` — numerical democratic capacity examples.
- `c/` — low-level scoring utility.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/democratic_futures_advanced.py
```
