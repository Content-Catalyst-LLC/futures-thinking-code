# Future Generations and Long-Term Responsibility

This is the professional companion repository directory for the Futures Thinking article:

**Future Generations and Long-Term Responsibility**

## Purpose

This directory operationalizes long-term responsibility as a reproducible inherited-burden, future-freedom, stewardship-capacity, intergenerational-equity, ecological-inheritance, institutional-durability, future-representation, precaution, reversibility, and adaptive-governance workflow. It includes synthetic intergenerational profiles, future-generation scenarios, strategy options, risk indicators, inheritance records, adaptive pathway parameters, SQL schemas, documentation, generated outputs, and multi-language computational examples.

## Directory

`articles/future-generations-and-long-term-responsibility/`

## Structure

- `python/` — standard-library and optional advanced workflows for inherited burden, future freedom, stewardship scoring, intergenerational strategy value, and long-term pathway simulation.
- `r/` — base R workflows for comparing intergenerational responsibility profiles and stewardship gaps.
- `julia/` — inherited-burden scoring examples.
- `sql/` — schemas for profiles, scenarios, strategies, risk indicators, inheritance records, and long-term pathways.
- `rust/` — command-line inherited-burden scoring scaffold.
- `go/` — stewardship scoring utility scaffold.
- `cpp/` — efficient scoring examples.
- `fortran/` — numerical long-term responsibility examples.
- `c/` — low-level scoring utility.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/future_generations_long_term_responsibility_advanced.py
```
