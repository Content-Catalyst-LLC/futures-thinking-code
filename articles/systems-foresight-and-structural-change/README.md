# Systems Foresight and Structural Change

This is the professional companion repository directory for the Futures Thinking article:

**Systems Foresight and Structural Change**

## Purpose

This directory operationalizes systems foresight and structural change as a reproducible futures workflow. It includes synthetic but realistic system-domain data, structural pressure scoring, feedback-loop registers, leverage-point analysis, signal-pressure diagnostics, structural change strategy pathways, monitoring triggers, SQL schemas, documentation, generated outputs, and multi-language computational examples.

## Directory

`articles/systems-foresight-and-structural-change/`

## Structure

- `python/` — standard-library and optional advanced workflows for structural pressure, leverage, feedback, signal, and strategy analysis.
- `r/` — base R workflows for structural pressure and leverage scoring.
- `julia/` — structural pressure examples.
- `sql/` — schemas for systems, feedback loops, leverage points, signals, strategies, and monitoring triggers.
- `rust/` — command-line structural diagnostics scaffold.
- `go/` — structural pressure utility scaffold.
- `cpp/` — efficient leverage-score examples.
- `fortran/` — numerical structural pressure examples.
- `c/` — low-level pressure scoring utility.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/systems_foresight_advanced.py
```
