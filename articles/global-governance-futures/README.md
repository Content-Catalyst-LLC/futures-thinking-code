# Global Governance Futures

This is the professional companion repository directory for the Futures Thinking article:

**Global Governance Futures**

## Purpose

This directory operationalizes global governance futures as a reproducible institutional-capacity, legitimacy-gap, collective-action, and adaptive-governance workflow. It includes synthetic governance profiles, scenario records, strategy options, risk indicators, institutional records, adaptive pathway parameters, SQL schemas, documentation, generated outputs, and multi-language computational examples.

## Directory

`articles/global-governance-futures/`

## Structure

- `python/` — standard-library and optional advanced workflows for governance capacity, legitimacy gaps, collective-action stress, strategy robustness, risk indicators, and adaptive governance simulations.
- `r/` — base R workflows for comparing governance futures and legitimacy gaps.
- `julia/` — global governance scoring examples.
- `sql/` — schemas for governance profiles, scenarios, strategies, risk indicators, institutional records, and adaptive pathways.
- `rust/` — command-line governance capacity scoring scaffold.
- `go/` — global governance utility scaffold.
- `cpp/` — efficient scoring examples.
- `fortran/` — numerical governance capacity examples.
- `c/` — low-level scoring utility.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/global_governance_futures_advanced.py
```
