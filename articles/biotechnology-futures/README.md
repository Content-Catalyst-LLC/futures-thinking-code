# Biotechnology Futures

This is the professional companion repository directory for the Futures Thinking article:

**Biotechnology Futures**

## Purpose

This directory operationalizes biotechnology futures as a reproducible futures workflow. It includes synthetic biotechnology capability records, readiness indicators, risk registers, justice indicators, scenario profiles, pathway simulations, strategy options, SQL schemas, documentation, generated outputs, and multi-language computational examples.

## Directory

`articles/biotechnology-futures/`

## Structure

- `python/` — standard-library and optional advanced workflows for biotechnology readiness, risk pressure, justice capacity, access capacity, pathway simulation, and reproducible reports.
- `r/` — base R workflows for biotechnology scenario comparison and justice/risk scoring.
- `julia/` — responsible biotechnology capacity scoring examples.
- `sql/` — schemas for capability registers, risk registers, justice indicators, scenario profiles, pathway parameters, and strategy options.
- `rust/` — command-line biotechnology readiness scaffold.
- `go/` — responsible biotechnology capacity utility scaffold.
- `cpp/` — efficient scoring examples.
- `fortran/` — numerical biotechnology readiness examples.
- `c/` — low-level scoring utility.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/biotechnology_futures_advanced.py
```
