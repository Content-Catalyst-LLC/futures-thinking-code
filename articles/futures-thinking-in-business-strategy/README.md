# Futures Thinking in Business Strategy

This is the professional companion repository directory for the Futures Thinking article:

**Futures Thinking in Business Strategy**

## Purpose

This directory operationalizes futures thinking in business strategy as a reproducible strategic-foresight workflow. It includes synthetic strategy profiles, future scenario datasets, strategic option portfolios, capability records, early-warning indicators, dynamic capability pathways, SQL schemas, documentation, generated outputs, and multi-language computational examples.

## Directory

`articles/futures-thinking-in-business-strategy/`

## Structure

- `python/` — standard-library and optional advanced workflows for business futures profiles, robustness, fragility, scenario stress testing, strategic options, and dynamic capability simulation.
- `r/` — base R workflows for comparing strategy futures profiles.
- `julia/` — strategy profile scoring examples.
- `sql/` — schemas for strategy profiles, scenarios, options, capability records, indicators, and pathways.
- `rust/` — command-line strategy scoring scaffold.
- `go/` — business futures utility scaffold.
- `cpp/` — efficient scoring examples.
- `fortran/` — numerical strategic viability examples.
- `c/` — low-level scoring utility.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/business_strategy_futures_advanced.py
```
