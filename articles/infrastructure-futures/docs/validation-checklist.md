# Validation Checklist

- [ ] Required directories exist.
- [ ] Standard Python workflow runs without external packages.
- [ ] Outputs are generated.
- [ ] SQL schema loads in SQLite if available.
- [ ] Advanced Python workflow fails gracefully if dependencies are missing.
- [ ] Strategy options reference valid infrastructure profiles.
- [ ] Risk indicators reference valid infrastructure scenarios.
- [ ] Governance records reference valid infrastructure profiles.
- [ ] Cascade pathways reference valid profiles and scenarios.
- [ ] Outputs include infrastructure profile scores, scenario scores, strategy scores, risk-priority scores, governance-capacity scores, pathway simulations, and a reproducibility report.
