# Validation Checklist

- [ ] Required directories exist.
- [ ] Standard Python workflow runs without external packages.
- [ ] Outputs are generated.
- [ ] SQL schema loads in SQLite if available.
- [ ] Advanced Python workflow fails gracefully if dependencies are missing.
- [ ] Strategy options reference valid profiles.
- [ ] Risk indicators reference valid scenarios.
- [ ] Extraction/voice records reference valid profiles.
- [ ] Adaptive pathways reference valid profiles and scenarios.
- [ ] Outputs include colonial profile scores, scenario scores, strategy scores, risk-priority scores, extraction/voice scores, adaptive simulations, and a reproducibility report.
