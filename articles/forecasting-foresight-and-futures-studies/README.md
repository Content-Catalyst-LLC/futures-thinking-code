# Forecasting, Foresight, and Futures Studies

Companion repository directory for the Futures Thinking article:

**Forecasting, Foresight, and Futures Studies**

This directory contains workflows and scaffolding for comparing forecasting, foresight, futures literacy, scenario work, and futures studies.

## Directory Structure

- `python/` — forecast error, scenario robustness, regret analysis, and strategy comparison examples
- `r/` — future-oriented practice profiles and comparison workflows
- `julia/` — dynamic uncertainty and robustness examples
- `sql/` — forecasts, drivers, signals, scenarios, assumptions, and strategy-evaluation schemas
- `rust/` — command-line futures diagnostics scaffold
- `go/` — signal and scenario utility scaffold
- `cpp/` — efficient scenario-performance examples
- `fortran/` — dynamic readiness examples
- `c/` — low-level scenario scoring utilities
- `docs/` — article notes and modeling principles
- `data/` — synthetic datasets
- `outputs/` — generated outputs
- `notebooks/` — notebook placeholders
