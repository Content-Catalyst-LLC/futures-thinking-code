# The Future of Work and Automation

This is the professional companion repository directory for the Futures Thinking article:

**The Future of Work and Automation**

## Purpose

This directory operationalizes the future of work and automation as a reproducible futures workflow. It includes synthetic occupation profiles, task-exposure matrices, work-scenario profiles, algorithmic management risk records, worker voice indicators, social protection indicators, pathway simulations, SQL schemas, documentation, generated outputs, and multi-language computational examples.

## Directory

`articles/the-future-of-work-and-automation/`

## Structure

- `python/` — standard-library and optional advanced workflows for task exposure, job quality, transition risk, skill mobility, automation pressure, worker voice, and reproducible reports.
- `r/` — base R workflows for work-automation future profiles and worker-centered capacity.
- `julia/` — job-quality and worker-centered scoring examples.
- `sql/` — schemas for occupation profiles, task exposure, scenario profiles, algorithmic management risks, social protection indicators, pathway parameters, and strategy options.
- `rust/` — command-line job-quality score scaffold.
- `go/` — worker-centered capacity utility scaffold.
- `cpp/` — efficient scoring examples.
- `fortran/` — numerical work-automation examples.
- `c/` — low-level scoring utility.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/work_automation_advanced.py
```
