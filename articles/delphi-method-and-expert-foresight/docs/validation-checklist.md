# Validation Checklist

- [ ] Required directories exist.
- [ ] Standard Python workflow runs without external packages.
- [ ] Outputs are generated.
- [ ] SQL schema loads in SQLite if available.
- [ ] Advanced Python workflow fails gracefully if dependencies are missing.
- [ ] Data dictionary matches CSV columns.
- [ ] Panel audit includes multiple forms of expertise.
- [ ] Consensus metrics include dispersion and stability, not only median ratings.
- [ ] Qualitative rationales are linked to decision implications.
- [ ] Foresight outputs connect Delphi findings to policy, scenario, research, or monitoring uses.
