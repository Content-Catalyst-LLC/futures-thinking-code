# Methodology

This companion repository treats foresight data systems and reproducible workflows as durable knowledge infrastructure for strategic foresight.

## Core Equations

### Data Quality

`quality = 0.25 × completeness + 0.25 × validity + 0.25 × freshness + 0.25 × source_traceability`

### Driver Priority

`priority = impact × uncertainty`

### Scenario Traceability

`traceability = 0.35 × linked_driver_coverage + 0.30 × assumption_coverage + 0.25 × evidence_coverage + 0.10 × review_status_score`

### Assumption Fragility

`fragility_score = 0.35 × (1 - confidence) + 0.35 × fragility + 0.30 × strategic_impact`

### Strategy Viability

`viability = 0.25 × effectiveness + 0.20 × feasibility + 0.20 × equity + 0.20 × legitimacy + 0.15 × adaptability`

### Workflow Integrity

`integrity = generated_outputs / expected_outputs`

Scores support review; they do not replace judgment. Foresight data systems should preserve interpretation, assumptions, source notes, stakeholder knowledge, limitations, and revision records.
