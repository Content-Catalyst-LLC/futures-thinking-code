# Futures Wheel and Impact Mapping

This is the professional companion repository directory for the Futures Thinking article:

**Futures Wheel and Impact Mapping**

## Purpose

This directory operationalizes Futures Wheel and Impact Mapping as a reproducible foresight workflow. It includes synthetic but realistic focal-change records, consequence cascades, graph edges, actor maps, impact pathways, intervention portfolios, monitoring indicators, power/distribution audits, SQL schemas, documentation, generated outputs, and multi-language computational examples.

## Directory

`articles/futures-wheel-and-impact-mapping/`

## Structure

- `python/` — standard-library and optional advanced workflows for consequence and impact-pathway analysis.
- `r/` — base R workflows for consequence priorities and actor-impact summaries.
- `julia/` — dynamic consequence-priority examples.
- `sql/` — schemas for focal changes, consequences, edges, actors, impact pathways, interventions, monitoring, and distributional audits.
- `rust/` — command-line consequence diagnostics scaffold.
- `go/` — impact-priority utility scaffold.
- `cpp/` — efficient consequence scoring example.
- `fortran/` — numerical impact scoring example.
- `c/` — low-level consequence scoring utility.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/futures_wheel_advanced.py
```
