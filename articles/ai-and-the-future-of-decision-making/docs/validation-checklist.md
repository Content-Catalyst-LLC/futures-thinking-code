- [ ] Required directories exist.

- [ ] SQL schema loads in SQLite if available.
- [ ] Advanced Python workflow fails gracefully if dependencies are missing.
- [ ] Governance controls reference valid decision systems.
- [ ] Risk indicators reference valid decision systems.
- [ ] Equity harm indicators reference valid decision systems.
- [ ] Pathway parameters reference valid decision systems.
- [ ] Decision-system scores include governance, contestability, equity, and uncertainty metrics.
- [ ] Reproducibility report is generated.
