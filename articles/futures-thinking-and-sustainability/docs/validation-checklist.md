# Validation Checklist

- [ ] Required directories exist.
- [ ] Standard Python workflow runs without external packages.
- [ ] Outputs are generated.
- [ ] SQL schema loads in SQLite if available.
- [ ] Advanced Python workflow fails gracefully if dependencies are missing.
- [ ] Transition strategies reference valid sustainability profiles.
- [ ] Risk indicators reference valid scenarios.
- [ ] Governance records reference valid sustainability profiles.
- [ ] Transition pathways reference valid profiles and scenarios.
- [ ] Outputs include sustainability profile scores, scenario scores, strategy scores, risk-priority scores, governance-capacity scores, transition simulations, and a reproducibility report.
