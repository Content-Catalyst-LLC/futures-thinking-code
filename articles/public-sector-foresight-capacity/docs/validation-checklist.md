# Validation Checklist

- [ ] Required directories exist.
- [ ] Standard Python workflow runs without external packages.
- [ ] Outputs are generated.
- [ ] SQL schema loads in SQLite if available.
- [ ] Advanced Python workflow fails gracefully if dependencies are missing.
- [ ] Decision uptake records reference valid capacity profiles.
- [ ] Adaptive pathways reference valid capacity profiles and scenarios.
- [ ] Outputs include capacity scores, signal scores, decision uptake scores, scenario scores, pathway simulation, and strategy scores.
- [ ] Reproducibility report is generated.
