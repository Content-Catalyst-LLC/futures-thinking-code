# Validation Checklist

- [ ] Required directories exist.
- [ ] Standard Python workflow runs without external packages.
- [ ] Outputs are generated.
- [ ] SQL schema loads in SQLite if available.
- [ ] Advanced Python workflow fails gracefully if dependencies are missing.
- [ ] Signal register includes novelty, relevance, urgency, evidence, affected voice, vulnerability, and lead time.
- [ ] Indicators include baseline, current value, threshold, owner, trigger rule, and response protocol.
- [ ] Assumptions include confidence, fragility, monitoring indicator, and revision rule.
- [ ] Cross-system cascade scores are generated.
- [ ] Response protocols link warnings to action, communication, and accountability.
