# Validation Checklist

- [ ] Required directories exist.
- [ ] Standard Python workflow runs without external packages.
- [ ] Outputs are generated.
- [ ] SQL schema loads in SQLite if available.
- [ ] Advanced Python workflow fails gracefully if dependencies are missing.
- [ ] Strategy options reference valid consumer future profiles.
- [ ] Vulnerability indicators reference valid consumer future profiles.
- [ ] Regulatory records reference valid scenarios.
- [ ] Adoption pathways reference valid consumer future profiles and scenarios.
- [ ] Outputs include consumer profile scores scenario scores strategy scores vulnerability scores regulatory scores adoption simulations and a reproducibility report.
