# Validation Checklist

- [ ] Required directories exist.
- [ ] Standard Python workflow runs without external packages.
- [ ] Outputs are generated.
- [ ] SQL schema loads in SQLite if available.
- [ ] Advanced Python workflow fails gracefully if dependencies are missing.
- [ ] Risk records reference valid institutions.
- [ ] Feedback records reference valid institutions.
- [ ] Adaptive pathways reference valid institutions and scenarios.
- [ ] Outputs include institutional scores, risk scores, feedback scores, scenario scores, pathway simulation, and strategy scores.
- [ ] Reproducibility report is generated.
