# Financial Futures and Systemic Risk

This is the professional companion repository directory for the Futures Thinking article:

**Financial Futures and Systemic Risk**

## Purpose

This directory operationalizes financial futures and systemic risk as a reproducible foresight and stress-testing workflow. It includes synthetic financial-system profiles, financial scenarios, policy options, risk indicators, climate/debt/public-finance records, systemic stress pathways, SQL schemas, documentation, generated outputs, and multi-language computational examples.

## Directory

`articles/financial-futures-and-systemic-risk/`

## Structure

- `python/` — standard-library and optional advanced workflows for systemic-risk scoring, financial resilience, stress testing, household fragility, climate exposure, debt pressure, nonbank exposure, and digital run risk.
- `r/` — base R workflows for comparing financial future profiles.
- `julia/` — financial resilience scoring examples.
- `sql/` — schemas for financial profiles, scenarios, policy options, risk indicators, public-finance records, and stress pathways.
- `rust/` — command-line financial resilience scoring scaffold.
- `go/` — financial futures utility scaffold.
- `cpp/` — efficient scoring examples.
- `fortran/` — numerical financial resilience examples.
- `c/` — low-level scoring utility.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/financial_futures_systemic_risk_advanced.py
```
