# Strategic Foresight Methods

This is the professional companion repository directory for the Futures Thinking article:

**Strategic Foresight Methods**

## Purpose

This directory operationalizes strategic foresight methods as a layered research and decision-support workflow. It includes synthetic but realistic datasets, method-profile scoring, signal watch scoring, driver criticality, assumption vulnerability, institutional uptake analysis, layered foresight pipeline simulation, SQL schemas, documentation, generated outputs, and multi-language computational examples.

## Directory

`articles/strategic-foresight-methods/`

## Structure

- `python/` — standard-library and optional advanced workflows for strategic foresight method analysis.
- `r/` — base R workflows for method profiles and layered foresight summaries.
- `julia/` — dynamic foresight capability examples.
- `sql/` — schemas for methods, signals, drivers, assumptions, pipelines, and strategy translation.
- `rust/` — command-line foresight diagnostics scaffold.
- `go/` — foresight capability utility scaffold.
- `cpp/` — efficient method-profile scoring examples.
- `fortran/` — numerical foresight-capability examples.
- `c/` — low-level foresight scoring utilities.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/strategic_foresight_advanced.py
```
