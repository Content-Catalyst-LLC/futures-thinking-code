# Data Dictionary

## foresight_methods.csv

Synthetic method-profile dataset comparing core strategic foresight methods across detection, ambiguity tolerance, structural depth, actionability, participation, institutional fit, learning value, and technocratic risk.

## pipeline_profiles.csv

Synthetic institutional foresight-system profiles used to simulate how detection, interpretation, pattern formation, uncertainty structuring, strategic design, legitimacy, uptake, and resistance affect actionable foresight.

## signals.csv

Emerging signals scored by uncertainty, impact, novelty, source type, and monitoring priority.

## drivers_uncertainties.csv

Drivers and critical uncertainties scored by uncertainty, impact, velocity, and domain.

## assumptions.csv

Foresight-process assumptions scored by confidence, exposure, reversibility, and monitoring signals.

## strategy_translation.csv

Links foresight insights to decision areas, action options, monitoring indicators, review frequency, and decision linkage.
