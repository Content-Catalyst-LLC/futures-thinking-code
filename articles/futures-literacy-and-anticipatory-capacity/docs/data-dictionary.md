# Data Dictionary

## capacity_profiles.csv

Scores organizational orientations across scanning, interpretation, assumption visibility, imagination range, participation, learning, and action translation.

## assumptions.csv

Synthetic assumptions with confidence, exposure, reversibility, and monitoring signals. Used for assumption vulnerability scoring.

## signals.csv

Emerging signals scored for uncertainty, impact, novelty, source type, and monitoring priority.

## future_images.csv

Future images held by different actor groups. Used to examine how expectations, emotions, assumptions, and participation needs vary.

## learning_cycles.csv

Institutional learning cycle examples with review frequency, participation level, decision linkage, and learning score.

## strategy_translation.csv

Links futures insights to decision areas, action options, monitoring indicators, and review frequency.
