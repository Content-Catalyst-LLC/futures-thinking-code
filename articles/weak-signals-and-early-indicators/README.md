# Weak Signals and Early Indicators

This is the professional companion repository directory for the Futures Thinking article:

**Weak Signals and Early Indicators**

## Purpose

This directory operationalizes weak signal and early indicator analysis as a reproducible foresight workflow. It includes synthetic but realistic signal registers, early indicator tracking, signal-profile scoring, signal amplification modeling, assumption challenge logs, propagation and friction analysis, monitoring criteria, SQL schemas, documentation, generated outputs, and multi-language computational examples.

## Directory

`articles/weak-signals-and-early-indicators/`

## Structure

- `python/` — standard-library and optional advanced workflows for weak signal and early indicator analysis.
- `r/` — base R workflows for signal profiles, indicator tracking, and monitoring summaries.
- `julia/` — dynamic signal amplification examples.
- `sql/` — schemas for weak signals, indicators, clusters, assumptions, propagation pathways, and watchlists.
- `rust/` — command-line weak signal diagnostics scaffold.
- `go/` — weak signal profile utility scaffold.
- `cpp/` — efficient signal scoring example.
- `fortran/` — numerical signal amplification examples.
- `c/` — low-level weak signal scoring utility.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/weak_signals_advanced.py
```
