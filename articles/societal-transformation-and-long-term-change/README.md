# Societal Transformation and Long-Term Change

This is the professional companion repository directory for the Futures Thinking article:

**Societal Transformation and Long-Term Change**

## Purpose

This directory operationalizes societal transformation and long-term change as a reproducible futures workflow. It includes synthetic transformation drivers, weak signals, scenario profiles, system-pressure indicators, equity and justice metrics, strategy options, pathway simulations, SQL schemas, documentation, generated outputs, and multi-language computational examples.

## Directory

`articles/societal-transformation-and-long-term-change/`

## Structure

- `python/` — standard-library and optional advanced workflows for transformation profiles, structural pressure, equity protection, pathway simulation, and reproducible reports.
- `r/` — base R workflows for transformation profiles and just-transition capacity.
- `julia/` — transformation capacity scoring examples.
- `sql/` — schemas for drivers, signals, scenarios, pressure indicators, equity indicators, strategy options, and pathway parameters.
- `rust/` — command-line transformation scoring scaffold.
- `go/` — just-transformation capacity utility scaffold.
- `cpp/` — efficient scoring examples.
- `fortran/` — numerical transformation viability examples.
- `c/` — low-level transformation scoring utility.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/societal_transformation_advanced.py
```
