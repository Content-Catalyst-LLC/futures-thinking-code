# Trend Analysis and Megatrends

This is the professional companion repository directory for the Futures Thinking article:

**Trend Analysis and Megatrends**

## Purpose

This directory operationalizes trend analysis and megatrend interpretation as a reproducible foresight workflow. It includes synthetic but realistic datasets, trend and megatrend profiling, structural-shift scoring, interaction mapping, signal monitoring, assumption vulnerability, strategy implications, SQL schemas, documentation, generated outputs, and multi-language computational examples.

## Directory

`articles/trend-analysis-and-megatrends/`

## Structure

- `python/` — standard-library and optional advanced workflows for trend and megatrend analysis.
- `r/` — base R workflows for trend profiles and long-term change summaries.
- `julia/` — dynamic trend momentum and structural-shift examples.
- `sql/` — schemas for trends, megatrends, interactions, signals, assumptions, indicators, and strategy implications.
- `rust/` — command-line trend diagnostics scaffold.
- `go/` — trend profile utility scaffold.
- `cpp/` — efficient profile-scoring examples.
- `fortran/` — numerical trend momentum examples.
- `c/` — low-level trend scoring utilities.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/trend_megatrend_advanced.py
```
