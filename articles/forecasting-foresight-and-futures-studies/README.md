# Forecasting, Foresight, and Futures Studies

This is the professional companion repository directory for the Futures Thinking article:

**Forecasting, Foresight, and Futures Studies**

## Purpose

Comparison of prediction, projection, forecasting, foresight, futures literacy, scenario work, and futures studies.

This article directory compares estimation, preparedness, and critical futures inquiry through forecast-error diagnostics, scenario robustness, practice profiles, and assumption analysis.

This directory is designed to be useful for researchers, analysts, policy teams, foresight practitioners, and institutional strategy teams. It includes synthetic but realistic datasets, reproducible workflows, robustness analysis, signal tracking, assumption vulnerability scoring, forecast-error diagnostics, strategy evaluation, SQL schema design, and multi-language computational examples.

## Directory

`articles/forecasting-foresight-and-futures-studies/`

## Structure

- `python/` — standard-library research workflow plus optional pandas/matplotlib workflow.
- `r/` — base R analysis for practice profiles, readiness, and signal-priority summaries.
- `julia/` — dynamic scenario and uncertainty examples.
- `sql/` — reproducible schema for drivers, signals, assumptions, forecasts, scenarios, strategies, and evaluations.
- `rust/` — command-line robustness diagnostics scaffold.
- `go/` — scenario and signal utility scaffold.
- `cpp/` — efficient strategy-performance calculations.
- `fortran/` — numerical readiness example.
- `c/` — low-level scenario scoring utility.
- `docs/` — methodology, assumptions, data dictionary, validation checklist, reproducibility notes.
- `data/` — synthetic but realistic futures-thinking datasets.
- `outputs/` — generated tables, summaries, and reports.
- `notebooks/` — notebook placeholders for exploratory analysis.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/futures_research_workflow_advanced.py
```
