# Ethics of Futures Thinking

This is the professional companion repository directory for the Futures Thinking article:

**Ethics of Futures Thinking**

## Purpose

This directory operationalizes ethical futures thinking as a reproducible intergenerational-responsibility, distributional-justice, participation, accountability, precaution, contestability, epistemic justice, and adaptive-learning workflow. It includes synthetic institutional profiles, ethical scenarios, strategy options, risk indicators, stakeholder distribution records, intergenerational pathways, SQL schemas, documentation, generated outputs, and multi-language computational examples.

## Directory

`articles/ethics-of-futures-thinking/`

## Structure

- `python/` — standard-library and optional advanced workflows for ethical futures profiles, justice-adjusted scores, distributional tradeoffs, and intergenerational pathway simulation.
- `r/` — base R workflows for comparing ethical futures profiles and accountability gaps.
- `julia/` — ethical futures scoring examples.
- `sql/` — schemas for profiles, scenarios, strategies, risk indicators, stakeholder burdens, and pathways.
- `rust/` — command-line ethical futures scoring scaffold.
- `go/` — ethical scoring utility scaffold.
- `cpp/` — efficient scoring examples.
- `fortran/` — numerical ethical futures examples.
- `c/` — low-level scoring utility.
- `docs/` — methodology, data dictionary, validation checklist, and reproducibility notes.
- `data/` — synthetic datasets.
- `outputs/` — generated output tables and reports.
- `notebooks/` — notebook placeholders.

## Quick Start

Run the default smoke test:

```bash
bash run_smoke_tests.sh
```

The default Python workflow uses only the Python standard library.

Optional advanced workflow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-advanced.txt
python python/ethics_of_futures_thinking_advanced.py
```
