# Validation Checklist

- [ ] Required directories exist.
- [ ] Standard Python workflow runs without external packages.
- [ ] Outputs are generated.
- [ ] SQL schema loads in SQLite if available.
- [ ] Advanced Python workflow fails gracefully if dependencies are missing.
- [ ] Emerging risks reference valid regulatory models.
- [ ] Rights-remedy records reference valid regulatory models.
- [ ] Sandbox records reference valid regulatory models.
- [ ] Adaptive pathways reference valid regulatory models and scenarios.
- [ ] Outputs include regulatory model scores, risk scores, rights-remedy scores, sandbox scores, scenario scores, pathway simulation, and strategy scores.
- [ ] Reproducibility report is generated.
