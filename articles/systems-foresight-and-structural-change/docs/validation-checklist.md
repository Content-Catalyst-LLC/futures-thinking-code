# Validation Checklist

- [ ] Required directories exist.
- [ ] Standard Python workflow runs without external packages.
- [ ] Outputs are generated.
- [ ] SQL schema loads in SQLite if available.
- [ ] Advanced Python workflow fails gracefully if dependencies are missing.
- [ ] Data dictionary matches CSV columns.
- [ ] System domains include stress, capacity, trust, interdependence, vulnerability, fragmentation, and lock-in.
- [ ] Feedback loops include harmful and beneficial loops.
- [ ] Leverage points are scored by structural depth and legitimacy.
- [ ] Monitoring triggers include review frequency and decision response.
